# ⬡ JARVIS - Personal AI Assistant

A local, private, voice-ready personal AI assistant built with React + FastAPI + Mistral AI.

## Features
- 🧠 Local AI (Mistral via Ollama) — free, private, offline
- 💻 Computer control — open apps, websites
- 🌐 Web search — search and summarize
- 🧠 Memory system — remembers your preferences
- 🎨 Iron Man HUD style interface

## Tech Stack
- Frontend: React + Vite
- Backend: FastAPI (Python)
- AI: Mistral (local via Ollama)
- Routing: Hybrid local/cloud AI
